#  Crust & Co.

A modern, mobile-first pizza ordering frontend built with React, Vite, Tailwind CSS and Framer Motion.

Crust & Co. is designed to feel like a polished food-delivery mobile application while remaining fully responsive on desktop screens.

---

##  Features

###  Home

- Modern pizza delivery homepage
- Delivery location card
- Promotional hero banner
- Quick service information
- Search functionality
- Pizza categories
- Best seller section
- Pizza menu
- Deals and offers
- Trust / quality section
- Rewards CTA
- Mobile bottom navigation

###  Pizza Menu

- Pizza cards with modern UI
- Pizza ratings
- Vegetarian indicators
- Bestseller / New badges
- Multiple pizza sizes
- Dynamic pricing
- Add to cart
- Favorite functionality
- Product details
- Smooth card animations

###  Search & Filtering

- Search pizzas by name
- Search by description
- Search by toppings
- Category filtering
- Minimum rating filter
- Popular sorting
- Rating sorting
- Price low-to-high
- Price high-to-low
- Empty search state
- Filter reset

###  Cart

- Add products to cart
- Increase / decrease quantity
- Remove products
- Clear cart
- Cart item count
- Free delivery progress
- Delivery fee calculation
- Promo codes
- Discount calculation
- BOGO offer support
- Order summary
- Checkout navigation
